# Alpha Cubs Preschool website

Static site, no build step needed.

## Deploy on Vercel
Option A (drag and drop): unzip, then at vercel.com/new drag the `alpha-cubs-preschool` folder in and click Deploy.
Option B (CLI): `npm i -g vercel`, then run `vercel --prod` inside this folder.
Option C (GitHub): push this folder to a repo, import it in Vercel, Framework Preset "Other", leave build command empty.

## Files
- index.html: the full site
- favicon.svg: browser-tab icon
- vercel.json: clean URL settings
